## Highlighted Work

**[WittyKeys](https://wittykeys.com)**  
Live Android AI keyboard and writing assistant powered by Claude through Firebase. The hard parts were not just prompt calls: keyboard trust, overlay behavior, subscription entitlements, quota/paywall states, Play Billing, real-device regression, Crashlytics/Performance, backend logs, and Play Store release work.

**AI-SDR**  
Human-reviewed outreach workflow for campaign setup, prospect research, Claude-assisted drafts, regeneration, approval queues, follow-up, analytics, and browser E2E boundaries. Final sends and account-sensitive actions stay approval-gated.

**SFOS - Solo Founder Operating System**  
The operating layer I built around WittyKeys: Cowork planning, Claude Code implementation, parallel git worktrees, 30+ slash commands, remote device deployment, golden screenshot regression, Espresso/UI Automator flows, LLM quality scoring, JourneyTracer observability, and release review.

## The Automation Layer

This is the part I want technical teams to notice.

| Layer | What it does |
| --- | --- |
| **AI-orchestrated development** | Cowork plans, Claude Code implements, I review and approve gates. Multiple frontend/backend worktrees let independent agents work in parallel. |
| **Automated UI development** | HTML/mockup references, structured implementation instructions, screenshot capture, visual comparison, issue triage, and fix loops. |
| **QA automation** | Golden screenshots, PixelDiffComparator, Espresso/UI Automator, real-device regression on Motorola Razr 50, and automated release checks. |
| **AI quality evaluation** | LLM-as-judge scoring for reply quality, tone, Hinglish naturalness, and context relevance. |
| **Observability** | JourneyTracer, sanitized product traces, backend logs, Crashlytics, Firebase Performance, and post-release checks. |
